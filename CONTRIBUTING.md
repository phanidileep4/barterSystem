# Contributing to BarterSystem

Thank you for helping explore whether technology can support useful, fair, and voluntary exchange.

BarterSystem is at an early discovery stage. Contributions that challenge the premise are as welcome as contributions that advance it.

## Good ways to begin

- Comment on or take a repository issue.
- Document a real exchange scenario and its failure modes.
- Propose a small, testable MVP workflow.
- Research matching, reputation, privacy, accessibility, moderation, or dispute resolution.
- Sketch a user flow or data model.
- Build a deliberately narrow prototype after discussing its scope in an issue.

## Before opening a pull request

1. Search existing issues and pull requests.
2. Open an issue before making a large architectural or product change.
3. Keep the change focused on one problem.
4. Explain the user need, tradeoffs, and safety implications—not only the implementation.
5. Never commit secrets, private personal data, production credentials, or copied proprietary material.

## Product expectations

Contributions should preserve these boundaries:

- Participation and every proposed exchange must be voluntary.
- AI recommendations must be explainable and overridable.
- The project must not assign a hidden score to a person's worth.
- Trust and safety cannot be postponed until after growth.
- The project is not a cryptocurrency, investment product, or mechanism for evading legal or tax obligations.

## Pull requests

A useful pull request description includes:

- the problem being addressed;
- the proposed behavior;
- alternatives considered;
- privacy, safety, accessibility, and abuse considerations;
- tests or evidence appropriate to the change.

Small pull requests are easier to review and learn from.

## Current development setup

There is not yet an application or selected technical stack. During the discovery phase, documentation and prototypes should include their own minimal run instructions. Once an MVP stack is selected, this guide will be updated with a shared development workflow.

## Community conduct

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
