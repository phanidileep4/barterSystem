# Roadmap

This roadmap is intentionally problem-first. Dates and technologies will follow evidence rather than lead it.

## Phase 0 — Understand the exchange problem

- Collect representative scenarios for skills, time, goods, and mixed exchanges.
- Identify where direct barter fails and where multi-party matching may help.
- Define participants, offers, needs, constraints, proposals, and exchange states.
- Document trust, safety, privacy, accessibility, tax, and legal questions.
- Decide what evidence would justify building an MVP.

## Phase 1 — Prototype matching

- Create a small synthetic dataset of offers and needs.
- Compare tag-based, semantic, and graph-based matching approaches.
- Prototype direct and multi-party exchange suggestions.
- Require a human-readable explanation for every suggested match.
- Evaluate match quality, bias, privacy, and failure modes.

## Phase 2 — Test one complete workflow

- Choose one bounded community or use case.
- Support profiles, listings, proposals, counteroffers, and exchange status.
- Add consent, blocking, reporting, and basic moderation paths.
- Use sample or consented data only.
- Conduct usability and safety testing before any broader release.

## Phase 3 — Limited community pilot

- Add authentication and appropriate access controls.
- Establish moderation and incident-response responsibilities.
- Add feedback without turning reputation into a simplistic universal score.
- Measure successful exchanges, failed matches, time to agreement, and safety incidents.
- Decide whether the project should expand, change direction, or stop.

## Questions that remain open

- Should exchanges stay bilateral, or are multi-party loops the defining feature?
- How should the system describe relative value without pretending value is objective?
- Can useful reputation remain contextual rather than becoming a permanent social score?
- Which data must never be sent to an AI model?
- How should disputes and incomplete exchanges be handled?
- What communities would benefit—and which could be harmed?
- What legal, labor, consumer-protection, and tax obligations apply in each deployment?
